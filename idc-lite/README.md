# IDC-Lite

Лёгкая утилита для управления LCD-дисплеем на водянках серии FX (VID `1A86`, PID `E317`). Написана на **.NET 8 + WPF** — никакого Electron, никаких проприетарных файлов ID-COOLING.

![](images/1.png)

---

## Преимущества перед стандартным софтом ID-COOLING

| | Оригинал ID-COOLING | IDC-Lite |
|---|---|---|
| **Технология** | Electron (Chromium) | .NET 8 WPF |
| **Потребление памяти** | ~200 МБ | ~50 МБ |
| **Отзывчивость** | Лагает при резкой нагрузке | Мгновенная |
| **Языки** | Только английский | 🇷🇺 Русский / 🇬🇧 English / 🇨🇳 中文 |
| **Распространение** | Инсталлятор + куча файлов | Один `.exe` |
| **Хранение настроек** | Разбросано по системе | Одна папка `%AppData%/idc-lite/` |
| **Лицензия** | Проприетарная | MIT |

---

## Системные DLL (используются только Windows API)

| DLL | Назначение |
|---|---|
| `kernel32.dll` | `CreateFileW` / `WriteFile` — отправка HID-отчётов на дисплей |
| `setupapi.dll` | Поиск USB HID-устройства в системе |
| `hid.dll` | Получение атрибутов HID (VID/PID) |
| `dwmapi.dll` | Нативная тень окна через DWM |

> **Никакие DLL из оригинального софта ID-COOLING не используются.**

---

## Возможности

- **Вывод температуры CPU на LCD-дисплей** в реальном времени
- **Выбор источника температуры:** авто / средняя ядер / хотспот / CPU Package
- **Мониторинг в трее:** температура, быстрый доступ к настройкам
- **Автозапуск** при старте Windows, сворачивание в трей
- **Высокий приоритет процесса** — никаких фризов в играх
- **Минималистичный интерфейс** в цветах Catppuccin Mocha
- **Полная локализация:** русский, английский, китайский

## Сборка

```bash
dotnet publish -c Release -r win-x64
```

На выходе — **один `.exe` файл**, полностью автономный (self-contained).

---

## Для реверс-инженеров

VID/PID и байты протокола (`0x55`, `0xBB`) заданы константами в `Services/HidService.cs`. Проведя реверс официального софта своей водянки, можно подменить эти значения и адаптировать утилиту под другие HID-дисплеи.

## О проекте

Мой первый проект. Писал для себя — стандартный софт ID-COOLING бесил лагами и жором памяти: при запуске игры он мог просто зависнуть намертво.

Код написан в паре с **Aider (GLM-5.2)**, но значительная часть написана руками. Выложил по приколу — пользуйтесь, если у вас такая же водянка. Лицензия MIT, делайте что хотите.
